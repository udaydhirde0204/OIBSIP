# Task 1: Advanced Interactive BMI Calculator

A modern, interactive Graphical User Interface (GUI) Body Mass Index (BMI) calculator built using Python and Tkinter for the Oasis Infobyte Internship (OIBSIP).

## Features
- **Dual Unit System Support:** Easily toggle between Metric (kilograms, meters) and Imperial (pounds, inches) units.
- **Dynamic Category & Visual Feedback:** Displays health status (Underweight, Normal weight, Overweight, Obese) with distinct color coding.
- **Personalized Health Tips:** Provides actionable fitness/diet suggestions based on the calculated BMI score.
- **Input Validation & Reset:** Built-in exception handling for non-numeric/negative inputs and a one-click reset button.

## Requirements
- Python 3.x
- `tkinter` module (included with standard Python installations)
