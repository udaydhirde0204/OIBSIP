# Task 2: Random Password Generator (GUI Version)

A secure and customizable Random Password Generator built with Python and Tkinter for the Oasis Infobyte Internship (OIBSIP).

## Features
- **Customizable Length:** Users can specify desired password length.
- **Character Selection:** Toggle uppercase, numbers, and special symbols.
- **Cryptographically Secure:** Uses Python's `secrets` module for secure generation.
- **Password Strength Indicator:** Evaluates password complexity (Weak, Moderate, Strong).
- **Clipboard Integration:** Instant copy-to-clipboard functionality.

## Requirements
- Python 3.x

## How to Run
```bash
py password_generator.py
