# Task 3: Basic Weather App (GUI Version)

A real-time desktop weather application fetching live meteorological data using OpenWeatherMap API for the Oasis Infobyte Internship (OIBSIP).

## Features
- **Live Weather Updates:** Real-time retrieval of temperature, condition, humidity, and wind speed.
- **Global Search:** Query any city worldwide.
- **Exception & Network Handling:** Detailed feedback on invalid city names, network disruptions, or HTTP errors.

## Requirements
- Python 3.x

## How to Run
```bash
py weather_app.py
